DealBoard — a Black Friday and Cyber Monday deal finder for make.fun's black-friday-deal-finder-01 bounty. 18 real deals, each found and checked by the agent on 27 Nov 2026 against the store's own listing or a publication reporting it, with the sale price, the usual price, the store link and the check time on every deal — plus a verdict that says whether the deal is really a deal (40% off or an all-time low earns "Real deal", 20–39% earns "Good deal", under 20% is "Check first"). Searchable and filterable by category, store and discount, sortable by discount, saving or price, with a page per deal and a phone layout. It runs in a browser from static files with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To build the submission output:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
